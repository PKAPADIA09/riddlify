# Riddlify

Riddlify is a daily riddles  app built with Expo (React Native and Expo).

This repository currently contains a production-oriented Home / Dashboard screen and a small, focused UI layer. The app is intentionally minimal: no backend wiring or mock data is included by default.

Quick start
1. Install dependencies

```bash
npm install
```

2. Start the dev server and open iOS simulator

```bash 
npm run ios
# or: npx expo start  # then press "i" to open simulator
```

Run on Android or web:

```bash
npm run android
npm run web
```
